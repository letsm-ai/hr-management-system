# نظام إدارة الموارد البشرية (HR Management System)

نظام متكامل لإدارة الموارد البشرية يشمل إدارة الموظفين، الحضور والانصراف، تقييم الأداء، المكافآت، العقود، والرواتب.

---

## 🚀 المميزات الرئيسية

### إدارة الموظفين
- إضافة وتعديل بيانات الموظفين
- إدارة العقود والوثائق
- نظام صلاحيات متعدد المستويات (RBAC)

### الحضور والانصراف
- استيراد بيانات البصمة من ملفات Excel
- حساب التأخير والغياب تلقائياً
- تقارير حضور شهرية
- تعديل أوقات الدخول/الخروج يدوياً

### تقييم الأداء الشهري
- حساب درجة الحضور تلقائياً من سجلات الحضور
- ربط مع ClickUp لحساب الإنتاجية
- تقييم الجودة يدوياً بواسطة المدير
- درجة نهائية موحدة (حضور 30% + إنتاجية 40% + جودة 30%)

### نظام المكافآت والحوافز
- حساب المكافآت بناءً على الأداء الفعلي
- مكافآت العقود، المجمع، الأوفرتايم، KPI، الأفكار
- معامل الأداء حسب التقييم الشهري
- تقرير حوافز شامل مع التصدير

### إدارة العقود
- عقود الموظفين وعقود العملاء
- تنبيهات انتهاء العقود
- إنشاء NDA تلقائي (PDF)

### تقارير الرواتب
- حساب الراتب الشهري تلقائياً من بيانات الحضور
- خصومات التأخير والغياب
- تعديل مباشر للأوقات مع إعادة الحساب
- حفظ التقارير واسترجاعها

### نظام المخالفات
- تسجيل المخالفات وخصمها من الراتب
- عرض المخالفات في تقرير الحوافز

### الإشعارات
- تنبيهات فورية لطلبات الإجازة
- تنبيهات انتهاء العقود
- إشعارات الموافقات

### مزامنة البيانات
- استيراد/تصدير بيانات النظام (JSON)
- مزامنة مع ClickUp

## ⚙️ التشغيل المحلي

### المتطلبات
- Node.js 18+
- pnpm 8+
- Python 3.10+
- PostgreSQL (أو حساب Neon)

### 1. إعداد الخادم الخلفي

```bash
cd app/backend

# إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو: venv\Scripts\activate  # Windows

# تثبيت التبعيات
pip install -r requirements.txt

# إعداد متغيرات البيئة
cp .env.example .env
# عدّل .env وأضف DATABASE_URL

# تشغيل الخادم
python main.py
# أو: uvicorn main:app --host 0.0.0.0 --port 8001 --reload
```

### 2. إعداد الواجهة الأمامية

```bash
cd app/frontend

# تثبيت التبعيات
pnpm install

# تشغيل خادم التطوير
pnpm run dev

# بناء للإنتاج
pnpm run build
```

### 3. التشغيل بـ Docker

```bash
# تشغيل كل الخدمات
docker-compose up -d

# الواجهة: http://localhost
# الخادم: http://localhost:8001
```
